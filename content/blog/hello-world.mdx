Welcome. This blog is powered by [Fumadocs](https://fumadocs.dev) running
_headless_ — it handles MDX, frontmatter and the table of contents, while the
pages are rendered with this site's own minimal styles.

## Writing a post

Drop an `.mdx` file into `content/blog/` with a little frontmatter and it shows
up here, sorted by date.

```ts title="greet.ts"
export function greet(name: string) {
  return `hi, ${name}`;
}
```

```ts title="greet.ts" showLineNumbers {2}
export function greet(name: string) {
  return `hi, ${name}`;
}
```

Inline code like `pnpm dev` and a package command both work. Install a dependency:

```bash
npm install fumadocs-core
```

That's the whole workflow.
