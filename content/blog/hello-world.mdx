I rebuilt my site. Figured the first post might as well be about the thing you're
reading it on.

This is a minimal portfolio and blog. Work, projects, a GitHub contributions graph,
and writing. That's it.

The stack is boring in the good way: Next.js 16, React 19 with the compiler on,
Tailwind v4, MDX via Fumadocs, Shiki for code, Motion for animation, and shadcn/ui
on Base UI so I'm not rebuilding a dropdown for the hundredth time.

That's the tour.

I'll write about actual things here soon.
